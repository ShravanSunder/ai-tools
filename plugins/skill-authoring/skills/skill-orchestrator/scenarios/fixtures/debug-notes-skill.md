# Debug Notes

Write notes while you debug. Keep them in the repo so the next person can pick up where you stopped.

## Workflow

1. Reproduce the failure and write the steps down.
2. Form a hypothesis and test it; note the result.
3. When the cause is found, write it up with the fix.

Notes go in `docs/debugging/<date>-<name>.md`. Write them for any debugging question.
