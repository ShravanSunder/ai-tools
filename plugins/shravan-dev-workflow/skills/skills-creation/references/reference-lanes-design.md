# Shared Output and Tool Shapes

This reference owns the decision to extract a stable output or tool shape. The caller returns the shape's named consumers, authoritative home, required fields, and validation route. Review checks and research source classes are agent-loaded steps, so their teaching stays in ordinary references.

## Output Shape

Extract a model-readable output shape only when two or more real consumers need the same fields and meanings. Define each required and optional field, enum value, and ordering constraint once. Keep the judgment, selection predicate, and completion rule in the calling workflow or teaching reference. A shape with one consumer stays local to that consumer.

## Tool Shape

Extract a tool shape when a tool, test, CI check, or runtime validates the structure. Name that validator and test the representation it consumes. A readable example does not establish a machine contract unless an actual validator reads it.

## Ownership Check

Return the consumers, the reason they need the same shape, the authoritative home, and the proof that the current caller can load or validate it. Link consumers to that home and remove duplicate field definitions in the same cutover. Do not preserve a forwarding stub for an old review-lane schema. A schema owns fields and labels; it does not own the workflow that produces them.
