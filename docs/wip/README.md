# WIP Tracker

This README is only an index for temporary work in `docs/wip`. Delete WIP files
when they are done, or promote the useful content into plans, durable docs, or
changelog entries.

Agent guidance for working in this folder lives in `AGENTS.md`.

## Where a new item goes

| Kind | Write here |
| --- | --- |
| Something to do next (this repo) | dated file below, listed under **Next tickets** |
| Skill-portfolio "do next" | `~/dev/memory-logs/skills/backlog/funnel.md` |
| Named skill-change proposal | `skills-authoring/<yyyy-mm-dd-name>/proposal.md` only |
| Recurring skill/agent failure | `~/dev/memory-logs/skills/log/` |
| One session went wrong | `~/dev/memory-logs/skills/investigation/` |
| Work trace (no board yet) | `work-trails/<yyyy-mm-dd-work-label>/` |

`plan-improve-repo` writes admitted plans under `docs/plans/` or a spec's `plans/`. It does not own this folder.
