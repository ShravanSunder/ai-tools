# 2026-09-28 Workhorse decomposition and PR breakdown

- `shravan-dev-workflow` 2.66.0. Implements `docs/wip/skills-authoring/2026-09-27-workhorse-decomposition/spec.md` (r14.1, with the cohesion amendment) and `docs/wip/skills-authoring/2026-09-28-breakdown-and-review-topology/spec.md` (r5 with the owner's one-PR Sidekick assignment).
- `manage-agents`: horizon is a property of the job (Step, Task, Run, Open), and one job table in `model-catalog.md` picks the model for any Operator, Worker, or Sidekick job from direction, span, and horizon (Luna medium, high, xhigh as ceilings; off Luna, Opus medium or Sol medium). Workhorse fit adds a seam check. Job pins (VERIFY, output, TIMEBOX, REPORT) go on every Worker, Operator, and Luna job. Commission owns the staffing table that sets each PR's Sidekick tier. Long agent-router turns use `conversation create` then `message send`. Opus low and Sol xhigh leave the catalog; Grok high is the usual reviewer.
- Why Luna is the default: an Artificial Analysis intelligence-versus-cost chart (data 2026-09-22, read by eye, not independently verified) put Luna at roughly 9 to 14 times cheaper per task than Sol or Opus low at matched rows, with its highest effort still costing cents. This is a dated cost ratio, not a benchmark claim.
- `plan-implementation` writes one breakdown per delivery (PR nodes, stacks, contract nodes, integration gates, riskiest first) and one plan per PR node, bound to its node and base. Each slice records `tier: <Workhorse | Daily driver> · <direction>/<span>/<horizon> · <reason>`; a throughput checkpoint and the PR independence test are in `slice-and-proof-design.md`; `plan-review.md` holds Main's review of each full plan before `ready`. Phase tokens carry the breakdown node.
- `orchestrator-implementation-goal` admits the breakdown and PR plans and never writes plans; a missing plan ends the run with `ready-for-planning`. Each Sidekick owns one PR, Main sequences stacks through `gh stack`, each review scope (one PR, or one stack layer) gets its reviewer, and Main runs integration gates on recorded heads.
- `orchestrator-design` ends continued delivery at the breakdown and first plans. `implement-plan`, `implementation-review`, `implementation-pr-wrapup`, `plan-handoff`, and `plan-improve-repo` follow the per-PR unit; a Workhorse boundary stop is a `plan-defect`. `plan-improve-repo` delegates audits by Workhorse-fit evidence unit, and `practices-research` may fan out units inside one source class.
- `practices-collaboration` and `practices-show-me-your-work`: bounded Workers and Operators skip work-home discovery and the trace entry.
- Cohesion pass (r14): each rule now has one home and its consumers cite it; the plan field is renamed `tier:`, the review file `plan-review.md`, the job-table sections replace the role tables, and the cost snapshot moved here. The skills and shared references shrink on net.
