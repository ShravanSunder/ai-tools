# 2026-10-06 skill-eval-runner

New package `packages/skill-eval-runner` (0.1.1, local; run with `pnpm --config.dlx-cache-max-age=0 dlx file:"$PWD/packages/skill-eval-runner"` from the repo root; pnpm dlx needs an absolute path).

- Commands: `validate`, `run`, `lint`, `done-bar`. Deno from the package's own `deno` dependency; ACPX as a library; subjects `gpt-6-luna` medium, judge leaves `gpt-6-luna` high.
- Each Run gets a snapshot of the repository (skills' `scenarios/` stripped, fixtures placed), the skill set under `.agents/skills/`, and an isolated Codex home; the runner refuses to start inside a Codex sandbox.
- Checks are decision trees: code steps over recorded actions, Jev cards (no engine yet, so always uncertain), judge leaves. Missing evidence is inconclusive; a fail is never hidden by a later pass.
- The regex-form pressure runner, its scenarios, schemas, and fixtures are removed from `tests/skills`, which keeps 24 static contract tests. The 16 `skill-authoring` scenarios and a proving set of four `shravan-dev-workflow` scenarios use the new form; 317 others are listed as not running in `docs/wip/skills-authoring/2026-10-06-unconverted-scenarios.md`.
- Validation: runner `deno test` 38 passed, fmt/check/lint clean; `tests/skills` 24 passed, `tsc` clean; `validate` loads all 20 new-form scenarios; `lint` finds nothing in `skill-authoring`. Known-bad proof: code and judge checks each failed for the intended reason, then the compliant run passed. Live batches over the 19 active scenarios: the last full batch passed 8 of 19 Runs with 69 judge calls (1 retry, 0 inconclusive). Its recorded 638k subject tokens is the sum of each Run's last model request, not real usage: on two measured Runs Codex logged about 4x the recorded number (open item in the Program Design). Failures were triaged against each scenario's original obligation: 8 real skill misses stay failing; four criteria worded stricter than their source were restored, each passing the real reply and failing a known-bad one. A fresh retest of the two Runs that failed only on a restored criterion passed both.
- `lint` resolves a `references/` path that another skill owns when the line names that skill (`` `other-skill`'s `references/x.md` ``). The retired skill-audit global-contract scenario is rewritten on three neutral fixture skills and active again; its first Run fails because skill-audit built the shared document it forbids. `run` and `done-bar` now exit 2 when `--scenario` names a draft or retired scenario, instead of exiting 0 with nothing run.
- `new-from-intent` done bars return `not-evaluable (jev-lint-unavailable)` until the Jev tool exists.
